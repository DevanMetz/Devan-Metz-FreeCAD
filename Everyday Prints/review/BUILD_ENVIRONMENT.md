# Build environment

Built on Windows with Python 3.13.3 and the pinned packages in requirements.txt.
CAD CLI version: cadgen 0.4.4. Geometry: build123d 0.11.1 / Open CASCADE 7.9.3.1.1.

The isolated local environment needed a small workaround for malformed Windows
system font files: `FontManager.register_folder` in its installed build123d
package skips `fontTools.ttLib.TTLibError`. No system fonts were changed. The
designs use no text outlines and do not depend on that machine-specific patch.
The coupon labels are ordinary cut geometry.

The local CAD Viewer runs through `python -m server_py.server --host 127.0.0.1
--port 3245`. The bundled npm launcher referenced a missing JS file, and its
Python launcher misclassified unused Windows ports as busy. The included server
itself runs and answers its status API.

The in-app browser returned `ERR_BLOCKED_BY_CLIENT` for the localhost Viewer.
The server status and catalog APIs were verified separately. Saved CAD snapshots
provide the visual review; the local viewer links can be opened in a browser
that permits localhost.

The installed snapshot CLI rejected a custom `section` job key despite its
render engine supporting it. Transparent detail snapshots were used instead,
and face measurements independently verify the soap-dish contact and drain gap.

The Playwright headless browser is cached locally under `.cad-cache/browsers`.
Set `PLAYWRIGHT_BROWSERS_PATH` to that absolute folder when rebuilding snapshots
on this workstation. Other machines can use the normal Playwright install.

All geometry checks, source cases, and mesh checks ran locally. These are
software checks. No physical prints have been tested.

The public `export_design.py` path uses build123d's STEP writer and Mesher
directly. It does not invoke the CAD skill or browser. A source-only copy in a
temporary directory successfully rebuilt twelve customized print files and five
assemblies; imported STEP geometry and exported meshes were checked.
Assemblies require the pinned cadgen Python library for their rigid joints.

The collection build requests mesh deflections of 0.005 mm linear and 0.05
radians angular. The standalone export uses 0.01 mm and 0.05 radians. The
resulting dimensions and volumes are checked against source geometry; a
deflection setting alone does not establish the measured error.

The validation report fingerprints the entry sources, shared geometry helpers,
STEP files, and print meshes. Packaging checks those fingerprints first. A
temporary copy with a modified lid source was rejected before an archive was
written, confirming the stale-geometry guard. Archive contents are also checked
with CRC and SHA-256 verification after packaging.

The reducer's section drawing is generated by `make_reducer_section.py` from
its default parameters using Matplotlib. It is an explanatory axial section,
with illustrative tube walls equal to `stop_inset`; the independent CAD checks
verify those reference tubes. SVG and PNG versions are included. Matplotlib
is only needed for this drawing, not for the standalone geometry exporter.
